# PlansHub

A modern, collaborative task management application that helps teams and individuals plan, track, and achieve their goals. PlansHub provides an intuitive interface for creating, organizing, and managing tasks with a beautiful light/dark mode design.

## 🌟 Features

- **📋 Task Management** - Create, edit, and delete tasks with titles and descriptions
- **🎨 Color-Coded Tasks** - Each task is assigned a random color for easy visual organization
- **🌓 Dark/Light Theme** - Toggle between dark and light modes for comfortable viewing
- **🔍 Search Functionality** - Quickly find tasks using the built-in search feature
- **💾 Persistent Storage** - All tasks are automatically saved to your browser's local storage
- **📱 Responsive Design** - Works seamlessly on desktop, tablet, and mobile devices
- **⚡ Real-Time Updates** - See changes instantly as you manage your tasks

## 🚀 Getting Started

### Installation

1. Clone the repository:
```bash
git clone https://github.com/Zking4ever/Plan-container.git
```

2. Navigate to the project directory:
```bash
cd Plan-container
```

3. Open `index.html` in your web browser or use a local server

## 📖 Usage

### Creating a Task
1. Click the **+** button to create a new task
2. Enter your task title and description
3. The task will automatically be assigned a color and saved

### Searching Tasks
- Use the search bar at the top to filter tasks by keywords
- Results update in real-time as you type

### Toggling Theme
- Click the theme button (sun/moon icon) in the header to switch between light and dark modes
- Your preference is maintained during your session

### Deleting a Task
- Click the trash icon on any task card to delete it
- The change is immediately saved
